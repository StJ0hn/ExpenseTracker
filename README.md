# Sistema de Controle de Despesas

Aplicação em interface de linha de comando (CLI) desenvolvida em Java para o gerenciamento lógico de finanças pessoais.

## Objetivo
Projeto de cunho educacional focado na aplicação prática dos pilares da Programação Orientada a Objetos (POO) e na manipulação de estruturas de dados em memória. O sistema prioriza a construção da lógica algorítmica e o controle de estado sem a dependência de frameworks externos ou bancos de dados.

## Tecnologias e Conceitos Aplicados
* Java Puro (CLI)
* Programação Orientada a Objetos (Classes, Objetos e Encapsulamento)
* Estruturas de Dados e Coleções (Manipulação de Listas em memória)

## Funcionalidades Principais
A aplicação oferece um fluxo de controle através de interação via terminal, permitindo:
* Inserção de Dados: Adição estruturada de novas despesas ao sistema.
* Exclusão de Registros: Remoção de despesas previamente cadastradas através da manipulação da coleção.
* Leitura e Relatórios: Visualização integral do histórico de despesas e processamento iterativo dos dados para a geração de um resumo financeiro consolidado.

## Como Executar Localmente

1. Clone o repositório:
git clone https://github.com/StJ0hn/ExpenseTracker.git

3. Acesse a pasta do projeto e compile o código-fonte:
javac Caminho/Para/SuaClassePrincipal.java

4. Execute a aplicação diretamente no terminal:
java Caminho.Para.SuaClassePrincipal
